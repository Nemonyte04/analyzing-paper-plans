This project applies data analytics and statistical reasoning to study the aerodynamic performance of different paper-aircraft designs. High-speed video data was transformed into structured datasets, enabling quantitative evaluation of lift, drag, and efficiency under low-Reynolds-number flight.

The core challenge was solving a cross-disciplinary problem at the intersection of physics and data science: extracting meaningful insights from noisy, limited experimental data while validating theoretical models with empirical evidence.

### Key methods and skills:

Video-derived time-series data extraction and feature engineering

Exploratory data analysis, visualization, and uncertainty quantification

Data-driven comparison of design performance and trade-offs

This project demonstrates practical problem-solving across domains, bridging experimental measurement, modeling, and analytics to extract insight from real-world data.
